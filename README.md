# InsightFlow

InsightFlow is a SaaS platform that ingests real‑time business data, stores it in PostgreSQL, runs AI‑powered anomaly detection on key performance indicators, and presents interactive dashboards with automatic alerting. It combines a Go‑based backend API, a Python microservice for machine‑learning inference, and a TypeScript/React frontend, all orchestrated with Docker and provisioned via Terraform.

## Features

- Real‑time KPI ingestion via REST API
- Automated anomaly detection using a trained ML model
- Interactive dashboards with drill‑down charts
- Configurable alerting via email and Slack webhook
- Role‑based access control for multiple tenant organizations
- Export of reports in CSV and PDF
- Docker‑based deployment for on‑prem or cloud environments
- Infrastructure as code with Terraform for AWS RDS and ECS

## Architecture

InsightFlow follows a micro‑service architecture. The Go backend provides a clean, type‑safe API for CRUD operations on KPI data and aggregates queries. Data is persisted in PostgreSQL with proper indexing for time‑series queries. A separate Python FastAPI service hosts the anomaly‑detection model, allowing independent scaling and GPU usage if needed. The React/TypeScript frontend consumes the API, renders charts with Recharts, and polls the AI service for anomaly flags. All services run in Docker containers orchestrated by Docker Compose in development and can be deployed to AWS ECS/Fargate via Terraform. Configuration is externalized via environment variables, and CI/CD pipelines in GitHub Actions run unit, integration, and end‑to‑end tests before publishing images to a container registry.

## Testing

The testing strategy includes:
- **Unit tests** for Go packages using `go test` with table‑driven cases, and for Python modules using `pytest`.
- **Integration tests** that spin up a Docker Compose stack (PostgreSQL, API, AI service) and run API contract tests with `Postman/Newman`.
- **Frontend tests** using Jest and React Testing Library for component rendering and state logic.
- **End‑to‑end tests** with Cypress that simulate user flows across the dashboard, including anomaly highlighting.
- **CI pipeline** in GitHub Actions runs linting, all test suites, builds Docker images, and pushes them only on successful test runs. Code coverage thresholds are enforced (80% for backend, 85% for AI service, 90% for frontend).
